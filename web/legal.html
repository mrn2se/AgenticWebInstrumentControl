Privacy

What this site does

The site is static. It sets no cookies, has no analytics, advertising or external fonts, has no accounts or forms, and sends nothing you do in the demo anywhere. All of it runs in your browser tab, and it loads files only from its own address.

Hosting by GitHub

This project collects no personal data and receives no visitor logs. The only data collected is by the host, GitHub Pages, which logs and stores your IP address for security purposes when you visit. For how GitHub handles that data, and for your rights and requests about it, see the GitHub General Privacy Statement.

Stored in your browser

If you choose a light or dark theme, your choice is stored in your browser's local storage as awic-theme, so that it lasts until you next visit. It is never sent anywhere, and clearing this site's data in your browser removes it. Nothing is stored otherwise. The Copy button in the install assistant writes to your clipboard only when you press it.

Links to GitHub

Following a link to GitHub, or downloading AWIC from there, is a visit to GitHub under its own privacy statement.
